 Recruitment Web Platform

A full-stack Recruitment Web Application built using Spring Boot and REST API.  
This project helps manage job postings, candidates, and recruitment process efficiently.

---

 Features

- 👤 User Management (Add / Update / Delete)
- 💼 Job Posting Management
- 📄 Candidate Application Handling
- 🔍 REST API based architecture
- 🗄️ Database integration (MySQL)
- ⚡ CRUD operations for all modules

--- technology

- Java
- Spring Boot
- Spring MVC
- REST API
- MySQL
- Hibernate / JPA
- Maven
- Git & GitHub
